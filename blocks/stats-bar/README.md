# Homepage – Stats Bar Block

Displays a row of statistics with large values and descriptive labels.

## Fields

| Field | Type | Required | Description |
|---|---|---|---|
| **Stats** | Repeater | Yes | Add each statistic |
| — Value | Text | Yes | The large number (e.g. "120+") |
| — Label | Text | Yes | Description below the value (e.g. "Active Members") |

## Usage

1. Add the **Stats Bar** block in the editor
2. Click **Add Stat** for each statistic
3. Enter the value and label
4. Publish to see the 4-column grid on the frontend

Layout adjusts responsively: 1 col on mobile, 2 on tablet, 4 on desktop.
