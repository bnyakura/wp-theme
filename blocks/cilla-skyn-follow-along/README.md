# Cilla Skyn Follow Along Block

Pulls a live Instagram feed into the page via shortcode.

## Fields

| Field | Type | Required | Description |
|---|---|---|---|
| **Instagram Feed Shortcode** | Text | No | Shortcode from your Instagram feed plugin, e.g. `[instagram-feed]`. |

## Notes

- No feed rendering of its own — install an Instagram feed plugin (e.g. Smash Balloon) and paste its shortcode into the field above. The block outputs it via `do_shortcode()`.
